# Cómo contribuir

¿Querés sumar un ejemplo en otro lenguaje (Java, C#, Go, Ruby…) o mejorar uno existente? ¡Bienvenido!

1. Hacé un fork y creá una rama.
2. Usá solo datos ficticios y nunca incluyas claves ni certificados.
3. Probá tu ejemplo con una clave de pruebas (`nd_test_`).
4. Abrí un pull request contando qué agrega.

Si tenés una duda sobre la API, escribinos a soporte@nextdata.uy o consultá la [guía para desarrolladores](https://www.nextdata.uy/desarrolladores).
